
# Algorithms and Data Structures Enhancement

## Project Overview

For this enhancement, I selected my Advising Assistance Program from CS 300: Data Structures and Algorithms. The program was developed using C++ and allows users to load course information from a CSV file, display courses in alphanumeric order, and search for individual courses and their prerequisites.

## Original Artifact

The original program used a binary search tree to store course information. Users could search for courses and view their immediate prerequisites. However, the program did not display the complete prerequisite path for courses with multiple levels of prerequisites.

## Enhanced Artifact

For my CS 499 enhancement, I added a recursive algorithm that displays the complete prerequisite path for a selected course. I also implemented circular dependency detection to prevent infinite recursion.

I added an unordered_map for faster course lookups while keeping the original binary search tree for displaying courses in order. Other improvements included duplicate course detection, better file path handling, and additional input validation.

## Skills Demonstrated

- C++ programming
- Binary search trees and hash-based lookups
- Recursive algorithms
- Circular dependency detection
- Data validation and error handling
- Software testing and debugging

## Course Outcomes

This enhancement demonstrates Course Outcomes 3 and 4 through the use of algorithmic principles, appropriate data structures, problem-solving, and testing to improve an existing program.
