
# Enhanced Advising Assistance Program

This folder contains the enhanced version of my CS 300 Advising Assistance Program, completed for the CS 499 Algorithms and Data Structures milestone.

The enhancements include recursive prerequisite traversal, circular dependency detection, an unordered_map for faster course lookups, duplicate course detection, and improved input validation.

The original binary search tree was retained for displaying courses in alphanumeric order.
