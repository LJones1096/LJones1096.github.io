
# Databases

## Event Tracker Android Application

For my third CS-499 enhancement, I selected the Event Tracker application that I originally developed in CS 360: Mobile Architect and Programming. The application was created using Java, Android Studio, and SQLite.

I enhanced the database by connecting events to individual user accounts and restricting event retrieval, updates, and deletes to the appropriate user. I also added searching and sorting features and improved password storage.

These enhancements demonstrate my understanding of database relationships, data management, security, and how database changes affect an application.
