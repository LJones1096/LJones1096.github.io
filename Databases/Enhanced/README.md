
# Enhanced Event Tracker Application

This folder contains my enhanced Event Tracker Android application for CS-499.

The application was developed using Java, Android Studio, and SQLite.

For my database enhancement, I connected events to individual user accounts and updated database queries to restrict event retrieval, updates, and deletes to the appropriate user.

I also added event searching and sorting, improved password storage using hashing, and implemented a database upgrade process.

These improvements demonstrate database design, data relationships, security considerations, and application development.
