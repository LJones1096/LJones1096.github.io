
# Software Design and Engineering Enhancement

## Project Overview

For this enhancement, I selected my 3D arcade project from CS 330: Computational Graphics and Visualization. The project was developed using C++ and OpenGL and includes a 3D arcade cabinet with textures, lighting, camera movement, and user controls.

## Original Artifact

The original arcade project allowed users to move around and explore the 3D environment. However, much of the rendering code was contained in one large method, which made the program harder to maintain and modify.

## Enhanced Artifact

For my CS 499 enhancement, I reorganized the rendering code into smaller methods responsible for different parts of the scene, including the environment, arcade cabinet, screen, and controls.

I also added proximity-based interaction. When the user approaches the arcade cabinet, pressing the F key changes the display between the Arcade Ready and Game Over screens. The program also prevents the screen from repeatedly switching when the key is held down.

## Skills Demonstrated

- C++ programming and OpenGL
- Software design and code organization
- Refactoring existing code
- User input and interaction handling
- Testing and debugging

## Course Outcomes

This enhancement demonstrates progress toward Course Outcomes 3 and 4 through improved software design, problem-solving, and the use of computing tools to implement additional functionality.
